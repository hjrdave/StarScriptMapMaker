Walser: A Free 18th Century Cartography Brush Set for Fantasy Maps
Version 2.2

Originally etched by Gabriel Walser in 1763
Converted to brushes by K. M. Alexander in 2019

Thanks for download this brush set and I hope you find them useful. (I’m sure Gabriel would agree.)

More details on this set and other brushes can be found at: kmalexander.com

Iconography

{{i.n}}
16 px grid, 1.5 px stroke, round caps and joins, 1.5 px live-area inset. 14 px variant for layer rows. Drawn in currentColor so state colour comes from the parent. Kind icons (Landmass, Lake, Stamp, Label, Layer) are always paired with a name — never colour alone.

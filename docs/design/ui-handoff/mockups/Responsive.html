Breakpoints

≥ 1360 — Full Layers 232 · canvas · Properties 288.
1180–1359 — Narrow Layers Layers narrows to 200 and hides counts. Properties stays at 288.
1024–1179 — Layers rail Layers collapses to a 40 pt rail (same as the user collapsing it). Click opens it as an overlay.
Minimum 1024 × 640 Both panels are rails; Properties opens as a floating inspector pinned top-right of the canvas. Window can’t shrink further.

Collapse rules

  • Left is always Layers, right is always Properties. Properties stacks the active tool’s settings on top (brush tips, the Asset picker, Label style) and the selection — or the active Layer when nothing is selected — below.
  • Collapsing Layers: the header button or ⌘⌥1 folds it to a 40 pt rail showing the selection path; click the rail to expand.
  • Toggles: ⌘⌥1 Layers, ⌘⌥2 Properties, ⇥ hides both (focus on the map; the tool dock stays).
  • User choice wins: a panel the user collapsed stays collapsed when the window grows; auto-collapse only reverses its own changes.
  • Resizable: Layers 200–360, Properties 260–360, drag the divider; double-click resets. Widths persist per Map window.
  • Tab bar: Home is always first and can’t be closed. Map tabs shrink from 220 to 120 pt, then scroll with chevrons. ⌘1 Home, ⌘2–9 jump, ⌘T New Map, ⌘W close (asks to save if dirty). Opening a Map that’s already in a tab focuses it.
  • Tool dock keeps all 9 tools at every size and always centres on the canvas area, never over a panel.
  • Status bar hides frame time first, then real-world coordinates, below 1180.
  • Canvas keeps its zoom centre when panels open or close, so the map never jumps under the cursor.

Retina-sharp icons (1× / 2×)

1× · 1 px strokes, hand-hinted
2× · 1.5 pt = 3 px strokes
Same 16-pt geometry, two rasters.
  • Source: one SVG per icon on the 16 pt grid, plus a hinted @1x SVG when the 1.5 pt stroke would blur at 1×.
  • Build step: rasterise with resvg into one texture atlas per scale (16 px and 32 px cells), white glyphs on transparent, packed with a build.rs.
  • Runtime: choose the atlas from ctx.pixels_per_point() (≥ 1.5 → 2×), draw with Image::tint(color) so state colour stays a token. Snap icon rects to whole physical pixels.
  • Other scales (Windows 125%/150%): use the 2× atlas downsampled with linear filtering; never upscale 1×.
  • Map content (Stamps, Labels) is rendered from vectors at canvas zoom, so it is never limited to these atlases.

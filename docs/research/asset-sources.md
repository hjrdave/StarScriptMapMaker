# Asset-source leads

Leads for art that could go into Asset packs, with the terms as stated and where each statement comes from. These are leads only. Nothing here is bundled into the default pack, and this file adds no pack manifest or art.

The fuller research notes live on the `research/asset-sources` branch (`docs/research/asset-sources.md`). This file records only the leads from issue #33.

| The itch.io and cartographyassets packs | **Unverified** leads from the original research. Not bundled. | Original research. |

## Notes

- Both `_ReadMe.txt` files say the set is "free for any use for any project" and distributed under a Creative Commons CC0 "No Rights Reserved" dedication, so it can be used commercially, adaptations can be distributed, and no attribution is required.
- The `.abr` files are Photoshop brush files. The pack loader does not read them, so using the art would need a conversion step that is out of scope here.
- The itch.io and cartographyassets leads have no confirmed licence. Read each page's terms before considering any of them.
